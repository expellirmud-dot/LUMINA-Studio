# Dispatch: Controller Role

## Actor
*   **Active Controller**: ChatGPT Web

## Scope of Authority
1.  **Phase A Approval**: Analyzes user-facing objectives and locks the `BRIEF.md` / `task.md`.
2.  **Implementation Review**: Assesses candidate reports and provides instruction updates.
3.  **Phase C Decision**: Inspects final QA logs and approves final commit/merge step.
4.  **Scope Boundary Enforcement**: Halts execution if task drift occurs.
