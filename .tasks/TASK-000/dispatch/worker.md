# Dispatch: Worker Role

## Actor
*   **Active Worker**: IDE Worker (Current Agent)

## Scope of Authority
1.  **Code & File Modifications**: Implements required code, configuration updates, and documentation files strictly within allowed limits.
2.  **Part Reporting**: Documents completion details after every implementation segment.
3.  **Owner Verification Pause**: Stops execution and waits for human validation at defined review gates.
4.  **CLI Validation**: Executes build, lint, and status commands to confirm integrity.
