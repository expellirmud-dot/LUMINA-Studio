# Dispatch: Verifier Role

## Actor
*   **Active Verifier**: CLI Tools / Project Scripts / Verification Agents

## Scope of Authority
1.  **Code Quality Checking**: Evaluates style rules, formatting limits, and TypeScript type-safety constraints.
2.  **Working Tree Auditing**: Reviews git-diff states to ensure no extraneous files were modified.
3.  **Visual Quality Checks**: Runs screenshots and layout audits to confirm no visual regressions.
4.  **Handoff Logging**: Updates the AI handoff logs upon successful validation.
