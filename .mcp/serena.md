# Serena MCP Notes

Project: LUMINA Studio

Use Serena for:
- Reading project structure
- Finding files
- Reviewing code organization
- Summarizing implementation status
- Checking whether changes stay within Phase 1

Do not use Serena for:
- Expanding scope
- Adding backend
- Adding database
- Adding auth
- Adding booking
- Adding dashboard
- Adding CMS

Required context:
- PROJECT_RULES.md
- AI_HANDOFF.md
- docs/BRAND.md
- docs/DESIGN.md
- skills/LUMINA_BOOTSTRAP/skill.md
