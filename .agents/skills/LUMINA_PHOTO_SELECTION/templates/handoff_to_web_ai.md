# Handoff to Web AI

Use this when passing a selected photo set to an AI or worker that updates the website.

## Hard Constraints

Use this selected image set only.

Do not redesign the website.

Do not decide permanent hero, layout, motion, or structure.

Do not edit unrelated website files.

Do not edit `portfolio.ts` unless explicitly instructed.

Prefer editing only the image configuration file, such as:

```text
src/config/images.ts
```

Run build after changes:

```bash
npm run build
```

Report:

1. files changed
2. selected images used
3. hero image used
4. hero sequence used
5. build result
6. any layout problems as notes only
