# Story Patterns

Use these as starting patterns. Adjust based on the actual event.

## Ordination

Preparation → Procession → Bathing → Ceremony → Family → Monk Transition → Closing

Possible roles:

- Preparation: quiet human detail
- Procession: movement and community
- Bathing: ritual and family connection
- Ceremony: key confirmation
- Family: emotional anchor
- Monk Transition: transformation
- Closing: resolved memory

## Wedding

Venue → Couple → Family → Ceremony → Guests → Party → Closing

Possible roles:

- Venue: context
- Couple: emotional center
- Family: relationship and meaning
- Ceremony: formal confirmation
- Guests: social world
- Party: energy
- Closing: afterglow

## Concert / Stage

Venue → Crowd → Artist → Interaction → Peak → Afterglow

Possible roles:

- Venue: atmosphere
- Crowd: energy
- Artist: identity
- Interaction: connection
- Peak: hero or featured
- Afterglow: closing

## Municipal / Public Event

Venue / Context → Officials / Opening → Activity → People → Detail → Group / Confirmation → Closing

Possible roles:

- Context: where and why
- Officials: record and public duty
- Activity: what happened
- People: public benefit and human value
- Detail: evidence and texture
- Group: confirmation
- Closing: complete record
