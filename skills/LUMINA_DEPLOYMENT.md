# LUMINA DEPLOYMENT

Before deploy:

- npm run lint
- npm run build

Use:

- vercel for preview
- vercel --prod for production

After production deployment record:

- Production URL
- Deployment status
- Date/time if available

Update:

- AI_HANDOFF.md
- reports/implementation_report.md
