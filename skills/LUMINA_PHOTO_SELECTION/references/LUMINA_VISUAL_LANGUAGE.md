# LUMINA Visual Language

LUMINA prefers photographs that feel real, warm, and human.

Prioritize:

- real moments
- quiet emotional weight
- human warmth
- clean but not sterile composition
- images that feel observed, not staged
- editorial rhythm
- feeling before spectacle
- beauty that supports memory

Avoid:

- fake luxury
- over-polished emptiness
- excessive posing
- generic stock-photo feeling
- effects that overpower the image
- layout tricks used to compensate for weak photo selection
- cold distance when the event needs warmth

Let the image be the main subject.
