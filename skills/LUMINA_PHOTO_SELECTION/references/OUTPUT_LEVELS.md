# Output Levels

Use these levels to separate broad archive value from website-facing editorial strength.

## final_40

Broad final set.

Use for:

- archive
- client delivery
- backup
- later review
- website experiments
- alternate crops or future layout tests

Selection character:

- covers the full event
- includes important people and moments
- allows some useful alternates
- can include supporting images that are not homepage-level

## web_20

Main story set for web gallery or portfolio.

Use for:

- website gallery
- event portfolio page
- concise story presentation

Selection character:

- tells the event clearly
- avoids unnecessary repetition
- balances context, ritual, emotion, people, detail, and closing
- keeps visual rhythm tight

## homepage_8

Sharpest set for homepage and featured sections.

Use for:

- homepage
- featured work
- section preview
- high-impact web presentation

Selection character:

- immediate visual pull
- strong LUMINA identity
- low repetition
- emotionally or visually memorable

## hero_5

Tight hero sequence candidates.

Use for:

- hero sequence
- rotating hero test
- opening experience test

Selection character:

- each image must be strong quickly
- avoid five images with the same emotional note
- include variation in distance, mood, and role
- should work without explaining the whole event

## Relationship Between Levels

`homepage_8` is usually a subset of `web_20`.

`web_20` is usually a subset of `final_40`.

`hero_5` is usually a subset of `homepage_8`, but one image may be excluded from homepage if it works only as an opening frame.
