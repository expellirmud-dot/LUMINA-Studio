# Good Dashboard Command Center

A strong operational dashboard:

- keeps the active task summary visible at the top
- separates commands from evidence and logs
- uses clear panel hierarchy instead of decorative noise
- makes the primary action obvious without hiding supporting context
- keeps error and blocker states readable

This is good because it helps the user answer:

- What task is active?
- What can I do now?
- What evidence do I have?
- What blocked the flow?
