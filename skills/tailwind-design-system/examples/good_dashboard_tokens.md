# Good Semantic Dashboard Tokens

Use tokens that map to purpose:

- `--color-surface`
- `--color-surface-elevated`
- `--color-border`
- `--color-primary`
- `--color-success`
- `--color-warning`
- `--color-danger`

This is good because:

- the same state always looks the same
- components do not invent local color meanings
- buttons, chips, and panels stay consistent
- the dashboard can scale without rewriting styles
