# Good Responsive Dashboard Layout

A good dashboard layout:

- starts with a single-column task summary on mobile
- stacks command, evidence, and timeline panels cleanly
- lets long command text wrap without widening the page
- uses consistent spacing between sections
- keeps actions easy to tap on small screens

This layout is good because:

- the user can read it without horizontal scrolling
- the active task stays visible
- panels collapse naturally instead of breaking the page
